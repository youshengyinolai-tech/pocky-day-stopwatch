# 11.11秒チャレンジ 🍫

11月11日「ポッキーの日」にちなんだ、見えないタイマーをぴったり **11.11秒** で止めるミニゲームです。

▶ https://youshengyinolai-tech.github.io/pocky-day-stopwatch/

## あそびかた
1. スタートを押すと READY → ランダムなタイミングで GO!（GO 前に押すとフライング）
2. 11.11秒だと思ったらストップ
3. ドラムロールのあと結果発表

## モード
- **ふつう**：3秒たつと溶けたチョコがタイムを覆い隠す
- **鬼**：GO! の瞬間からチョコで何も見えない

## 演出
- ランク P(ERFECT) / S / A / B / C / D の判定スタンプ
- PERFECT はフラッシュ＋スティックの紙吹雪＋ファンファーレ
- 大きく外すとポッキーが「ポキッ！」と折れる
- 効果音は Web Audio で合成（右上で ON/OFF）

スペースキー / Enter / タップで操作できます。記録はブラウザに保存されます。
