# 11.11秒チャレンジ 🍫

11月11日「ポッキーの日」にちなんだ、チョコに隠れたタイマーを **お邪魔に負けず** ぴったり **11.11秒** で止めるミニゲームです。PC・iPad（全画面）での使用を想定しています。

主催：東京理科大学生協学生委員会 神楽坂支部

▶ https://youshengyinolai-tech.github.io/pocky-day-stopwatch/

## あそびかた
1. スペースキー（iPad はタップ）で READY → ランダムなタイミングで GO!（GO 前に押すとフライング）
2. タイムがチョコに隠される
3. お邪魔に惑わされず、11.11秒だと思ったらスペース
4. ドラムロールのあと結果発表

`F` キーで全画面。Enter・クリックでも操作できます。
iPad では画面のどこをタップしても操作できます（Safari の共有 →「ホーム画面に追加」から開くと全画面になります）。

## 設定
- **MODE**：ふつう（3秒で隠れる）／鬼（GO! の瞬間から隠れる）
- **JAMA**：なし／あり／地獄

## お邪魔の種類（生協・ポッキー尽くし）
- 生協・学生委員会・友だちなどからの偽通知
- 生協の店内放送（チャイム＋流れる帯）
- レジのバーコード「ピッ」音（わざとズレたテンポ）と値札
- レシートがジジジと印刷されて出てくる
- 生協のシャッターが下りてくる
- 生協のカートがガラガラ横切る
- ポッキーが飛んでくる／ポッキーの雨
- 「ポッキー 7本」などデタラメな本数カウント
- 「レジ袋いりますか？」などのウソの声かけ
- 偽タイム表示、画面の傾き・ぼかし・反転、偽のストップ音

## ランキングと管理サイト
Firebase を設定すると、全端末で同期するランキングと、管理サイト（`admin.html`）が使えるようになります。設定しなければ、ゲームはこれまでどおり単体で動きます。

管理サイト ▶ https://youshengyinolai-tech.github.io/pocky-day-stopwatch/admin.html

学生委員会で共有しているパスコードで入れます（`admin.html#k=パスコード` のリンクを開いても入れます）。一度入った端末では、次から入力は不要です。

- ランキング：記録の一覧・個別削除・全削除
- 判定：段階の追加・削除・並べ替え、文字・表示名・秒数・色・演出
- お邪魔：全体の頻度・出る時間帯・地獄の同時発動率と、13 種類それぞれの細かい設定（オン・オフ、出やすさ、時間帯、表示時間・大きさ・本数・速さ・文言など）。▶ 試す で保存前にプレビューできる
- 表示テキスト：タイトル・生協名・団体名・お知らせ

保存するとゲーム画面にすぐ反映されます。会場でネットが切れても、最後に受け取った設定で動き、記録はつながったときに送られます。

パスコードを変えるときは、ルールの `PASSCODE` を新しいものにして公開し、Firestore の `admins` コレクションを削除します（入室済みの端末も締め出されます）。

### Firebase の設定手順
1. https://console.firebase.google.com で「プロジェクトを作成」（Google アナリティクスはオフで可）
2. **Firestore Database** →「データベースを作成」→ 本番環境モード、ロケーションは `asia-northeast1`（東京）
3. Firestore の「ルール」タブに [firestore.rules](firestore.rules) の中身を貼り、`PASSCODE` を管理画面のパスコードに書き換えて「公開」（パスコードはこのリポジトリには書かない）
4. **Authentication** →「始める」→ ログイン方法に **匿名** を追加
5. Authentication →「設定」→「承認済みドメイン」に `youshengyinolai-tech.github.io` を追加
6. プロジェクトの設定（⚙）→「マイアプリ」でウェブアプリ（`</>`）を追加し、表示された `firebaseConfig` の中身を [firebase-config.js](firebase-config.js) の `null` と置き換える

```js
window.FIREBASE_CONFIG = {
  apiKey: "...",
  authDomain: "...",
  projectId: "...",
  storageBucket: "...",
  messagingSenderId: "...",
  appId: "..."
};
```

※ `firebaseConfig` は公開しても問題ない値です（守りは Firestore のルールで行っています）。

※ 非公式のファンメイド作品です。
